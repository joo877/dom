# DOM Manipulation – JavaScript Practice

A JavaScript project focused on practicing DOM (Document Object Model) manipulation and understanding how JavaScript interacts with HTML elements to create dynamic and interactive web pages.

## ✨ Features

- **DOM Selection:** Selecting HTML elements using JavaScript.
- **Content Manipulation:** Dynamically updating text and HTML content.
- **Element Creation:** Creating and inserting new HTML elements.
- **Element Removal:** Removing elements from the DOM.
- **Attribute Manipulation:** Getting, setting, and modifying HTML attributes.
- **Class Manipulation:** Adding, removing, and toggling CSS classes.
- **Event Handling:** Responding to user interactions using event listeners.
- **Dynamic UI Updates:** Updating page content without reloading.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- DOM API

## 🚀 Getting Started

### Installation

Clone the repository:

```bash
git clone https://github.com/joo877/dom.git
```

Navigate to the project directory:

```bash
cd dom
```

Open the main HTML file using Visual Studio Code and run it with Live Server.
